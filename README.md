# Projeto-2

Projeto desenvolvido com o objetivo de praticar conceitos de **responsividade utilizando HTML e CSS**.

## 🎯 Objetivo

O principal objetivo foi desenvolver um layout capaz de se adaptar em dois tamanhos de tela:

- 🖥️ Desktop
- 📱 Mobile

## 🛠️ Tecnologias

- HTML5
- CSS3
- Figma
- Flexbox
- Media Queries
- Google Fonts (Poppins)

## 📚 Conceitos praticados

- Desenvolvimento de layouts responsivos
- Flexbox
- Media Queries
- Adaptação de elementos para diferentes resoluções
- Organização e simplificação do CSS
- Estrutura semântica do HTML

## 🚀 Projeto

Este projeto faz parte da minha jornada de aprendizado em **Desenvolvimento Front-End**, com foco na construção de interfaces responsivas e na aplicação prática de HTML e CSS.
